## Навчальний план курсу: "Веб-розробка для початківців"

**Цільова аудиторія:** Студенти без досвіду в IT.

---

### 1. Загальні цілі курсу:

Основна мета курсу – надати студентам міцну основу у веб-розробці, яка дозволить їм самостійно створювати прості веб-сайти та розуміти основні принципи роботи Інтернету. Ми прагнемо:

*   **Демистифікувати веб-розробку:** Розбити складні концепції на зрозумілі кроки.
*   **Надати практичні навички:** Навчити використовувати основні інструменти та мови програмування для створення реальних веб-сторінок.
*   **Сформувати фундамент для подальшого навчання:** Підготувати студентів до глибшого вивчення окремих аспектів веб-розробки (фронтенд, бекенд, бази даних).
*   **Розвинути логічне мислення та навички вирішення проблем:** Веб-розробка вимагає аналітичного підходу, який буде розвиватися протягом курсу.
*   **Заохотити до самостійного навчання та дослідження:** Надати інструменти та ресурси для подальшого розвитку.

---

### 2. Тривалість та формат:

*   **Тривалість:** 10-12 тижнів (приблизно 2-3 місяці).
*   **Формат:** Змішаний (Blended Learning).
    *   **Онлайн-лекції:** Записані відео або живі вебінари з поясненням теорії та демонстрацією коду.
    *   **Практичні заняття/воркшопи:** Онлайн або офлайн сесії для відпрацювання матеріалу, вирішення завдань та відповідей на запитання.
    *   **Самостійна робота:** Виконання домашніх завдань, проєктів, читання додаткових матеріалів.
    *   **Менторська підтримка:** Доступ до викладачів/менторів для консультацій та допомоги.

---

### 3. Основні теми (5-7 пунктів):

**Модуль 1: Вступ до Веб-розробки та Основи HTML (2 тижні)**

*   **Що таке веб-сайт та як він працює:** Клієнт-серверна архітектура, браузери, URL, HTTP.
*   **Основи HTML:** Структура HTML-документа, основні теги (заголовки, параграфи, списки, посилання, зображення), атрибути.
*   **Семантичний HTML:** Важливість використання правильних тегів для доступності та SEO.
*   **Практика:** Створення перших статичних веб-сторінок.

**Модуль 2: Стилізація Веб-сторінок за допомогою CSS (3 тижні)**

*   **Вступ до CSS:** Синтаксис, способи підключення (inline, internal, external).
*   **Селектори:** Типи селекторів (класові, ID, тегові, псевдокласи).
*   **Базові властивості CSS:** Колір, фон, текст, розміри, відступи (margin, padding).
*   **Моделі блоків та рядків (Box Model):** Розуміння взаємодії елементів.
*   **Flexbox та Grid Layout:** Сучасні методи розташування елементів на сторінці.
*   **Адаптивний дизайн:** Основи створення сайтів, що добре виглядають на різних пристроях.
*   **Практика:** Стилізація створених HTML-сторінок, створення простих макетів.

**Модуль 3: Інтерактивність за допомогою JavaScript (3 тижні)**

*   **Вступ до JavaScript:** Роль JavaScript у веб-розробці, синтаксис.
*   **Змінні, типи даних, оператори:** Основи програмування.
*   **Керуючі конструкції:** Умовні оператори (if/else), цикли (for, while).
*   **Функції:** Створення та виклик функцій.
*   **Маніпуляція DOM (Document Object Model):** Зміна вмісту та стилю елементів сторінки за допомогою JavaScript.
*   **Обробка подій:** Реакція на дії користувача (кліки, введення тексту).
*   **Практика:** Додавання інтерактивності до веб-сторінок (кнопки, форми, прості анімації).

**Модуль 4: Робота з Формами та Валідація (1 тиждень)**

*   **HTML-форми:** Теги для створення форм (input, textarea, select, button).
*   **Типи полів вводу:** Текст, пароль, чекбокси, радіокнопки, дата тощо.
*   **Базова валідація форм на стороні клієнта (JavaScript):** Перевірка коректності введених даних перед відправкою.
*   **Практика:** Створення інтерактивних форм з базовою валідацією.

**Модуль 5: Інструменти Розробника та Основи Git (1-2 тижні)**

*   **Інструменти розробника в браузері:** Інспектування елементів, консоль, мережеві запити.
*   **Вступ до системи контролю версій Git:** Для чого потрібен Git, базові команди (init, add, commit, push, pull).
*   **Робота з GitHub/GitLab:** Створення репозиторіїв, спільна робота.
*   **Практика:** Використання інструментів розробника для налагодження, збереження коду за допомогою Git.

**Модуль 6: Розгортання Веб-сайту (1 тиждень)**

*   **Основи хостингу та доменних імен.**
*   **Прості методи розгортання статичних сайтів:** GitHub Pages, Netlify, Vercel.
*   **Практика:** Публікація свого першого веб-сайту в Інтернеті.

---

### 4. Методи навчання:

*   **Демонстраційні лекції:** Покрокове пояснення матеріалу з показом коду в реальному часі.
*   **Практичні завдання (Coding Challenges):** Невеликі завдання для закріплення кожного нового концепту.
*   **Проєктна робота:** Поступове створення власного веб-сайту протягом курсу, який включатиме вивчені технології.
*   **Рецензування коду (Code Review):** Отримання зворотного зв'язку від викладачів/менторів щодо написаного коду.
*   **Групові дискусії та Q&A сесії:** Можливість поставити запитання та обговорити складні моменти з викладачами та іншими студентами.
*   **Використання онлайн-ресурсів:** Рекомендація та інтеграція онлайн-платформ для навчання (наприклад, MDN Web Docs, freeCodeCamp, Codecademy).
*   **Парне програмування (Pair Programming):** Можливість працювати над завданнями у парах для обміну досвідом.

---

### 5. Що зможе робити студент після курсу:

Після успішного завершення курсу "Веб-розробка для початківців" студент зможе:

*   **Розуміти базові принципи роботи Інтернету та веб-сайтів.**
*   **Створювати статичні веб-сторінки** з використанням HTML, надаючи їм структуру та вміст.
*   **Стилізувати веб-сторінки** за допомогою CSS, роблячи їх візуально привабливими та адаптивними до різних пристроїв.
*   **Додавати базову інтерактивність** до веб-сторінок за допомогою JavaScript, реагуючи на дії користувача.
*   **Створювати та валідувати прості форми** для збору даних користувачів.
*   **Використовувати інструменти розробника в браузері** для налагодження та аналізу веб-сторінок.
*   **Використовувати Git для контролю версій свого коду** та співпраці (на базовому рівні).
*   **Розгортати свої статичні веб-сайти** в Інтернеті.
*   **Самостійно шукати інформацію та вирішувати типові проблеми** у веб-розробці.
*   **Створити своє перше портфоліо** з кількома простими веб-проєктами.

Цей курс стане чудовою відправною точкою для подальшого розвитку в галузі веб-розробки, дозволяючи студентам визначити свої інтереси (фронтенд, бекенд) та продовжити навчання.

        *   Основи HTML: структура документа, теги, атрибути.
        *   Семантичний HTML5: заголовки, параграфи, списки, посилання, зображення, таблиці.
